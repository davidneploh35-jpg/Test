# Фото каталога -> 3:4 (1920x2560)

`photo_fix.py` обходит сайт, скачивает фотографии товаров и кадрирует каждую по правилу
её категории. Всё готовое складывается в одну папку.

## Установка (один раз)

```bash
pip install requests beautifulsoup4 pillow numpy mediapipe
```

`mediapipe` находит фигуру человека и линию пояса — с ним кадр точнее.

Под Windows он собран только для Python 3.9-3.12, и последняя версия там 0.10.21.
На Python 3.13 и новее он не поставится — тогда ставь Python 3.12 либо работай без
него: скрипт это переживёт и перейдёт на поиск силуэта по фону, кадр будет грубее.
Проверено на mediapipe 0.10.21 и 1.0.1.

На Linux ему могут понадобиться системные библиотеки:
`apt-get install libegl1 libgles2`.

## Три команды

```bash
# 1) разведка: скачать фото и посмотреть, что нашлось. Кадрирование не делается
python photo_fix.py https://dr-arushanof.ru/index.php --crawl

# 2) рабочий прогон: скачать и скадрировать всё, кроме трикотажа
python photo_fix.py https://dr-arushanof.ru/index.php --crawl --max-pages 300 --fix

# 3) переобработать уже скачанное, не трогая сайт
python photo_fix.py --local photos_ready/original --fix
```

Первая команда обходит сайт и складывает оригиналы в `photos_ready/original`, но
кадры не режет: сначала стоит посмотреть `report.csv` и убедиться, что правильно
разложились категории. Если нет — поправить таблицу `CATEGORY_RULES` в начале
`photo_fix.py` под реальные адреса разделов и запустить вторую.

## Правила кадра

| Категория | Что попадает в кадр |
|---|---|
| Костюмы | В полный рост: от макушки с запасом до стоп |
| Штаны | По пояс: от линии талии до стоп, головы в кадре нет |
| Блузки | От макушки до точки чуть ниже пояса |
| Халаты | В полный рост |
| Трикотаж | Пропускается целиком |
| Всё остальное | В полный рост |

Горизонтальные фотографии становятся вертикальными во всех категориях: кадр берётся
вокруг модели, а если фигура в вертикаль не вписывается — недостающее сверху и снизу
достраивается продолжением фона.

Голова никогда не режется кадром. Если она обрезана в самом исходнике и полной версии
на сайте не нашлось, фотография не обрабатывается, а откладывается в `need_manual/` —
дорисовать её автоматически нечем.

## Что получается

```
photos_ready/
  kostyumy__007_dsc1234.jpg     все готовые файлы, 1920x2560, JPEG качества 95
  bluzki__011_img77.jpg
  original/                     что скачалось с сайта, как есть
  need_manual/                  голова обрезана в оригинале — нужна ручная дорисовка
  report.csv                    построчно по каждому файлу
```

Колонки `report.csv`:

| Колонка | Что означает |
|---|---|
| `category`, `rule` | Какая категория определилась и по какому правилу резался кадр |
| `w`, `h` | Размер исходника |
| `status` | `ready`, `head_cropped_in_source`, `skipped_category`, `duplicate`, `too_small`, `skipped_existing` |
| `body` | Как нашли фигуру: `pose` (точно), `silhouette` (по фону), `fallback` (не нашли) |
| `padded` | Сколько процентов кадра — достроенный фон. Больше 30% стоит посмотреть глазами |
| `upscaled` | Исходник был мельче 1920 по ширине и его растянули: резкость ниже |
| `note` | Пометки, в том числе «правило кадра ослаблено» |

Строки со `status = ready` и пустыми `padded`/`upscaled` — это кадры, которые не
требуют проверки. Начинать просмотр стоит с остальных.

## Полезные ключи

| Ключ | Зачем |
|---|---|
| `--redo` | Переделать даже то, что уже лежит в папке результата. Без него готовое не трогается — так повторный запуск не портит уже принятые фото |
| `--local ПАПКА` | Работать с папкой на диске вместо сайта. Категория берётся из имени подпапки |
| `--rule-override bluzki=below_waist` | Правило для ключевого слова, без правки файла |
| `--no-pose` | Не использовать mediapipe, только силуэт на фоне |
| `--min-side 400` | Порог отсева иконок и логотипов |
| `--quality 95` | Качество JPEG |

## Ограничения

Скрипт не умеет дорисовывать то, чего нет на фотографии. Если голова срезана в
оригинале, он это распознаёт и откладывает файл, но не восстанавливает лицо —
для этого нужен отдельный инструмент генерации изображений.

Достройка фона — это продолжение краёв кадра с размытием, а не выдуманное
изображение. На однотонном студийном фоне она незаметна, на пёстром — видна,
поэтому её доля вынесена в отчёт.
